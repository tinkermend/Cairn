# 识途前端设计规范

版本：v1.2 · 更新：2026-09-10 · 状态：当前设计基线，已接入 Web 全局主题。

识途采用**冷静蓝白、轻量专业、可观测轨迹清晰的企业级 SaaS 工作台**设计语言。默认浅色；蓝色用于操作和选中，紫色限定于 AI，轨迹、节点、精确边界与克制空间光构成产品视觉签名。

界面建立在**三层平面**上：导航白（`surface-nav`）、内容画布冷灰蓝（`surface-page`）、卡片白（`surface-card`）。三者必须彼此可分辨——这是 v1.1 的核心修订，v1.0 把侧边栏、顶栏与画布设成同一个值，导致全站只有两个平面。

本目录定义全局设计语言与基础组件规范。当前工程处于脚手架阶段，本次不设计、开发或假定已有任何具体业务模块，不以演示页面反推产品流程。后续模块设计在此基础上展开，并按宪法另写功能方案。

## 约束与事实源

- 宪法中 [UI 核心原则与索引](../../../CLAUDE.md#24-ui-的核心原则) 规定产品设计方向；本目录展开可以演进的设计细节。
- 语义和使用规则以本目录文档为准；可执行的颜色、字体、尺寸值以 `tokens.css` 为准；视觉样本只展示应用效果。
- 设计系统使用现有 **shadcn/ui + Radix + Tailwind**。不引入第二套 UI 框架，不重写已有基础交互。
- 新界面统一消费语义 Token。页面不得自选色板、重新定义按钮尺寸或引入独立状态含义。
- 深色主题不属于本轮设计交付；正式接入时明确浅色默认策略，不把现有脚手架暗色变量视为已经完成设计。
- 规范齐全不等于组件全部实现。组件的当前可复用情况见[落地约定](implementation.md)，缺少的组件按实际功能需求逐个补齐。

## v1.1 修订

按真实渲染实测（登录后逐页抓 computed style）修订，不是纸面调整：

| 修订 | 原因 |
| --- | --- |
| 新增 `surface-nav` / `surface-header`，画布 `#F7F9FC` → `#F1F4FA` | 原先侧边栏、顶栏、画布同色，卡片与画布明度比只有 1.05:1，全站只有两个平面 |
| 卡片改 `border-card` + 双层 `shadow-card` | 原先 1px 边框叠 4% alpha 阴影，两种边界语言各出一半力气，谁都没立住 |
| 输入改 `surface-control` 填充 + 内阴影，边界仍 ≥3:1 | v1.1 曾用浅底减轻边界压力；**v1.2 已撤销这层填充** |
| 主按钮携带 `action-shadow` | 该签名原本只出现在登录页，登录后全站掉回模板默认 |
| 自托管 Inter 拉丁子集 | 规范按 Inter 设计，但从未自托管，实际一直在按系统字体渲染 |
| 中文标题去负字距 | `tracking-tight` 是 Inter 拉丁字的 tracking，套到中文会挤压字身 |
| 字号刻度映射进 `--text-*`；删除 22 个与 Tailwind 重合的尺寸 Token | 未映射进 `@theme` 的 Token 页面消费不到，规范看起来比实际落地的完整 |
| 侧栏与顶栏连成连续的 L 形壳，内容嵌为独立面板；侧栏形态不再可配 | 残留的 `layout_variant` cookie 曾把侧栏渲染成悬浮卡片，而删掉 ConfigDrawer 后没有任何界面能改回来 |
| 页面层 33 处字号迁到职务刻度；`transition-all` 清零；页面说明加 72ch 上限 | 规范写了数值，代码一直没接 |
| `check.mjs` 新增三条源码断言（硬编码色 / `transition-all` / 页面层字号） | 宪法 §18.18：约束应由自动化检查卡住，而不是依赖自觉 |

## v1.2 修订

| 修订 | 原因 |
| --- | --- |
| `surface-control` 改回与 `surface-card` 同色纯白 | v1.1 的 `#F7F9FC` 浅底叠在白卡片上发灰，像禁用态。输入靠 `border-control` + 内阴影识别，不再另铺浅灰或冷白填充。`check.mjs` 断言两 Token 解析值相同，防止再回归 |

## 维护方式

修改共用颜色、尺寸或状态时，同步更新 Token、对应规范与视觉样本。功能模块只引用本规范，不复制一套数值。无法由当前组件表达的真实需求，先判断能否组合已有组件，再补充最小必要的变体。

运行 `node docs/design/front/check.mjs` 可检查文档内部链接、核心色对对比度、样本交互与桌面布局；使用项目已有 Playwright，不新增依赖。
