# 组件设计规范

版本：v1.0 · [返回索引](README.md) · [视觉样本](preview.html)

本文件规定基础组件如何呈现和交互，不要求一次性实现全部组件。优先复用现有 shadcn/ui 与 Radix，缺少的组合在实际需求出现时补充。尺寸和颜色引用 [Design Token](tokens.css)。

## 1. 统一状态契约

所有组件均需判断以下八种状态是否适用。**不适用（—）意味着没有这种交互语义，不是未完成设计**。静态标题不应为满足清单被添加 Hover 或 Disabled；容器的数据状态也不等于容器自身可点击。

| 状态 | 含义 | 通用视觉与行为 |
| --- | --- | --- |
| Default | 可正常阅读或交互 | 语义底色、可读文字、稳定尺寸；标签先于输入 |
| Hover | 指针位于可操作区域 | 使用 action-hover / 变体 hover；不改变布局；不作为唯一信息入口 |
| Active | 正在按下 / 激活瞬间 | 深一级颜色或内侧阴影，不与持久选中混淆 |
| Focus | 键盘或辅助技术焦点 | 按钮、开关、导航项使用 2px focus-ring + 3px 间隔；输入类控件在指针激活和键盘焦点时都使用 1px 主蓝边界 + 紧贴的 2px 半透明外光，不用外扩实线环；聚焦后不自动提交或导航 |
| Disabled | 当前不可操作 | 中性底、禁用文字；禁用真实交互；必要原因以可读文本提供 |
| Loading | 等待操作或数据 | 稳定尺寸、动作文字改为“保存中…”等；设置 aria-busy，防重复提交 |
| Error | 校验失败或请求失败 | 深红文字 + 图标 + 明确原因；给可执行恢复动作；保留用户输入 |
| Selected | 持续选中 / 当前 / 展开 | 浅蓝底、深蓝文字、勾选或指示线，并设置对应 aria/data 状态 |

叠加规则：Disabled 阻止动作；Loading 阻止同一请求重复发起；Error 保留至错误被修正或重新验证；Focus 始终可见。Selected 可以叠加 Focus 与 Hover，不能因为 Hover 丢失选中指示。错误输入获得焦点时保留错误边界与说明，同时显示统一焦点环。

只读使用 `readOnly` 或静态值展示，仍可聚焦、选择和复制，不等同于 Disabled。权限不足由权限规则决定可见性；若禁用入口有助于理解，旁边提供权限说明，不能只放在禁用按钮的 Tooltip 里。

### 1.1 状态族

下表定义可复用的八态规范；后续清单为**每个组件明确分配状态族**，并列出必要差异。八态从状态族继承，组件特例优先于通用默认。

| 状态族 | Default | Hover | Active | Focus | Disabled | Loading | Error | Selected |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| B 动作 | 变体底色与文案 | 变体 hover | 深一级 / 内阴影 | 统一焦点环 | 禁止触发，保留尺寸 | 图标位进度 + 动作文字 | 邻接错误 / 可重试 | 普通动作 —；切换动作 aria-pressed |
| F 输入 | 标签、边界、值 / 占位 | 边框可加深 | 点击激活输入 | 焦点环、光标 | 原生 disabled | 关联查询提示；可继续输入则不禁用 | aria-invalid + 字段下错误 | 文本选择 / 选择值由控件表达 |
| C 选择 | 未选轮廓 | 浅交互底 | 按下色 | 整个控件可见焦点 | 禁止切换 | 请求待确认；原选择保留 | 组内错误；回滚失败的乐观操作 | 填充 / 勾 / 开关位移 + 语义状态 |
| N 导航 | 中性文字 | 浅蓝底 / 下划线 | 按下色 | roving tabindex 或链接焦点 | 不可达原因明确 | 保留当前项并提示目标加载 | 目标区错误，导航仍可用 | 当前项浅蓝或蓝色指示线 |
| D 数据容器 | 真实内容与口径 | 仅可点击子项反馈 | 仅可点击子项反馈 | 仅交互子项 / 必要滚动区 | 静态内容 —；操作按权限禁用 | 等尺寸 Skeleton / 保留旧值并标记更新中 | 容器内说明与重试 | 仅行 / 项选择时适用 |
| T 静态展示 | 语义内容 | —；可点击版按 B | —；可点击版按 B | —；可交互版按 B | — | 上层容器提供占位 | 内容本身可表达错误状态 | — |

| R 反馈 | 结果 / 提示及动作 | 仅内部动作 | 仅内部动作 | 只在需要行动时接收焦点 | 提示本身 — | 进度态明确 | 错误级别替换语义，解释原因 | — |
| G 图表 | 图形 + 图例 + 数据摘要 | 值提示 / 关联高亮 | 明确支持时钻取 | 数据点或等价数据表可达 | 数据 —；不可用操作禁用 | 同尺寸图形占位 | 图区错误；过滤条件保留 | 系列 / 数据点选中有线型或符号辅助 |

## 2. Button

按钮用于动作，链接用于导航；不要使用可点击 `div` 模拟按钮。默认按钮高度 36px、左右 padding 12–16px、字号 14px、字重 500；图标 16px，图文间距 8px。

| 尺寸 | 高度 | 文字 | 纯图标按钮 |
| --- | --- | --- | --- |
| Small | 32px | 13px | 32 × 32px |
| Medium | 36px | 14px | 36 × 36px |
| Large | 40px | 14px | 40 × 40px |

| 组件 / 变体 | 状态族 | Default / 用途 | 状态差异 |
| --- | --- | --- | --- |
| Primary | B | 蓝 600 + 白字，操作区最高强调 | Hover/Active 蓝 700；不使用浅蓝白字 |
| Secondary | B | 浅蓝底 + 深蓝字，次要动作 | Hover 浅蓝底并出现深色细边界；Active 内阴影 |
| Outline | B | 白底 + 中性边框 | Hover 浅蓝；必要时加深边框；不能与 Disabled 混同 |
| Ghost | B | 透明底 + 正文色，用于工具栏 | Hover 才出现浅底；Focus 仍完整可见 |
| Text | B | 深蓝字，无外框 | Hover/Focus 可出现下划线；点击区域不压缩到文字轮廓 |
| Danger | B | 深红底 + 白字，仅破坏性确认 | Hover/Active 保持深红并加强边界；触发后在确认弹层提交 |
| Icon Button | B | 与所属变体一致，有名称和 Tooltip | Hover 与 Focus 都显示名称；Loading 不丢失名称 |
| Split Button | B + N | 左侧默认动作，右侧菜单独立焦点 | 默认动作忙碌时禁用相关选项；菜单展开使用 aria-expanded，非永久 Selected |

Loading 保留按钮宽度和主语，不显示模糊的“处理中”替代所有动作。普通按钮没有 Selected；切换工具使用 `aria-pressed`，不能用 `.active` 同时表达按下和持久选中。

操作失败后允许重试，并在字段、弹层或相关区块显示错误；不能只将按钮变红后消失。删除等高影响操作以明确的对象名和后果二次确认。

## 3. Form

### 3.1 基本布局与校验

标签默认位于控件上方，与控件间隔 8px。必填用文字或星号并提供说明；占位文字用于例子，不能代替标签。辅助文案与错误文案通过 `aria-describedby` 关联。

输入框默认 36px 高、8px 圆角、左右 12px 内边距；认证等高聚焦表单使用 48px。表单首屏以一列为主，仅强关联的短字段并排。避免对齐造成长中文标签挤压输入区。

首次输入不逐键报错；在离开字段或提交时校验，已有错误可随修正及时验证。提交后聚焦第一处错误；多个错误提供可跳转摘要。校验错误保留字段值，网络错误保留整份表单。

### 3.2 高聚焦表单与输入质感

输入使用与卡片相同的白底（`surface-card` / `surface-control`），再配 1px `border-control` 与 `control-shadow` 内阴影。输入靠边界识别，不另铺浅灰或冷白底；禁用态才使用 `surface-subtle`。边界负责满足 3:1 的识别对比度，不得为了“看起来轻”去削弱边界或重新加一层脏底。

不使用 `inset 0 1px 0 #fff` 之类的外凸高光，那是拟物时代的做法；内凹用 `control-shadow`。Hover 加深为 `border-control-hover`；Focus 使用 1px 主蓝边界和紧贴的 2px `focus-halo`（`control-focus-shadow`），不用 `ring-offset` 外扩实线环；Error 使用红色边界与 `error-halo`。这些状态由共用 Input / Textarea / Select / PasswordInput 提供，页面只选择高度，不另写边框、光晕或阴影。

科技感来自精确边界和克制的状态光，不在输入框外再套一道高饱和实线环，也不在框内添加无语义图标、渐变描边或持续动画。前后缀图标必须帮助识别输入含义或触发明确动作；密码显隐属于有效动作，并保留可访问名称。

| 组件 | 状态族 | 结构 / 规范 | 八态中的特例与键盘行为 |
| --- | --- | --- | --- |
| Input | F | 固定标签、可选前后缀、清除按钮 | Selected 指文本选择；清除按钮有名称；Enter 仅按所属表单约定提交 |
| Textarea | F | 默认至少 3 行，可垂直拉伸 | Enter 换行；禁止自动把 Enter 当提交；超限在下方说明 |
| Number Input | F | 单位、步长、上下限明确 | 允许编辑过程中的暂态值；离焦 / 提交校验；不静默截断或替换为零 |
| Password | F | 可切换显隐，允许粘贴和密码管理器 | 显隐按钮有 aria-pressed 与名称；错误不回显敏感值 |
| Search | F | 放大镜、清除、结果数 | 请求返回前保留关键字；无结果是空态；不把“无结果”标红 |
| Select | F + N | 显示已选标签，菜单展示选项 | 方向键定位、Enter 选择、Escape 关闭；选项勾选与高亮焦点独立 |
| Multi Select | F + C | 选值为可移除标签；溢出为“+N” | 关闭单个标签有名称；保留已选项；异步失败不清空选择 |
| Cascader | F + N | 明确层级路径、面包屑与当前层 | 每级独立 Loading/Error；回到上级不丢失已确认路径；无需求不提前实现 |
| Date Picker | F + N | YYYY-MM-DD 展示，明确范围 / 单日 | 日期不可选有原因；键盘输入与日历等价；不用颜色单独表示范围 |
| Time Picker | F | 24 小时制 HH:mm，可按需含秒 | 显示时区；允许键盘输入；非法时间就地报错 |
| Checkbox | C | 16px 视觉框 + 更大点击区域 | checked / unchecked / indeterminate 明确；Space 切换；组错误置于组下 |
| Radio | C | 单选组有组标题 | 方向键切换组内值；Tab 进入 / 离开组；默认值不能替代用户必须明确的决定 |
| Switch | C | 标签表达开关控制的内容 | Space 切换；开启状态蓝底 + 滑块位置；服务拒绝时恢复原值并解释 |
| Upload | F + D | 点击上传与拖入等价，列出格式 / 大小 | 每文件进度、取消、失败重试和移除；先校验再上传；成功后展示文件名 |
| Tag Input | F + C | Enter 添加，明确分隔规则 | 无输入时 Backspace 不直接连续删除；标签删除可键盘到达；重复值给就地反馈 |
| Code Input | F | 等宽字体、语言标签、复制 | Tab 是否缩进需明确且有逃离方式；错误含行列；不自动执行代码 |
| JSON Editor | F | 等宽输入 + 校验 / 格式化 + 错误位置 | 保留无效原文；解析失败不清空；只读仍可复制；普通需求用 Textarea 组合 |

日期范围的结束日不得早于开始日；时区与保存语义在具体功能方案里确定。表单控件不偷偷转换用户输入的时区或计量单位。

## 4. Navigation

导航只负责定位与上下文，不承载运行状态事实。键盘行为优先继承 Radix / Router 的成熟实现。

| 组件 | 状态族 | 结构 / 尺寸 | 特殊状态与交互 |
| --- | --- | --- | --- |
| Sidebar | N | 224px / 收起 72px；导航行 40px | 当前页 aria-current；收起保留名称、数量和当前标记；展开偏好可持久化 |
| Submenu | N | 同组二级项，28px 缩进 | 父项 aria-expanded；展开不自动改变当前页；Escape 按上下文收起 |
| Breadcrumb | N | 13px 文字 + 中性分隔 | 末项当前页不可点击；中间过长可折叠，不能只留不可识别图标 |
| Tabs | N | 文本标签 + 2px 当前指示线 | aria-selected 与 roving tabindex；左右键切换；昂贵加载用手动激活 |
| Steps | N / T | 编号、名称、当前 / 完成状态 | 流程不允许跳转时为 T；允许跳转时才是 N；错误步骤保留名称与原因 |
| Pagination | N | 上一页、页码、下一页、页大小、总数 | 边界按钮 Disabled；翻页 Loading 保留当前数据与定位；筛选后回首屏 |
| Dropdown Menu | O + N | 选项行至少 32px，相关项分组 | 方向键、Home/End、Escape；关闭返回触发器；危险项分隔并带文字 |

导航项的 Selected 是当前位置，不能混同于悬停；菜单高亮是暂时键盘焦点，勾选项是持久选择。网络失败不得使整个导航栏不可用。

## 5. Data Display

### 5.1 Table

默认表头 40px、行 48px、单元格左右 16px，正文 13px。表头 sticky 时不得遮挡焦点。列按主标识、关键值、状态、元信息、操作组织；具体字段由模块方案决定。

搜索 / 筛选 / 排序 / 分页必须形成同一查询上下文。全选区分“当前页 N 项”和“所有匹配项”，批量操作明确作用范围。未选择行时不占用整条批量操作栏。

大数据默认服务端分页，不下载全部记录再前端过滤；实际出现长列表瓶颈再引入虚拟化。虚拟化不能牺牲键盘、朗读顺序、表格语义或选中项一致性。

| 组件 | 状态族 | 规范 | 特殊状态 / 边界 |
| --- | --- | --- | --- |
| Table | D + C | 明确表头、行名、排序、选择与分页 | Hover 浅蓝；Selected 勾选 + 浅蓝底；加载时保留列宽；错误保留筛选；无结果不显示假零值 |
| Card | D | 白底、12px 圆角、1px 边界 | 静态卡无 Hover/Active/Focus；整卡链接不可包裹其他交互按钮 |
| Statistic Card | D | 标签、28px 数值、单位、时间范围 | 无样本显示“—”与说明；Loading 用数字位置 Skeleton；变化值注明对比基期 |
| Description List | T | `dl/dt/dd`，标签与值对齐 | 长值换行，技术值可复制；缺省用“未设置”，不隐藏条目造成误读 |
| Tag | T；可移除版 B | 12/18px，6px 圆角 | 普通标签非按钮；可选标签按 C；删除有可访问名称与撤销策略 |
| Badge | T | 状态图标 + 文字；数量可封顶 99+ | 精确数量可读取；禁止把数字变成无名称红点；错误是业务语义而非组件报错 |
| Avatar | T；入口版 B | 24 / 32 / 40px，等比例裁切 | 图片失败回退姓名缩写；邻接姓名时图片可装饰；入口版提供名称 |
| Tooltip | O | 简短补充，不承载必读错误和交互 | Hover/Focus 都可打开；Escape 关闭；不能让用户必须移动指针才能阅读 |
| Popover | O | 轻量筛选 / 简短详情 | aria-expanded；可点击内部内容；非模态不强制全页焦点陷阱；关闭返回触发器 |
| Timeline | D | 时间、事件标题、结果与可选详情 | 当前项可选时按 C；展开详情可键盘操作；无事件给空态；长事件按需展开 |
| Tree | N + C | 缩进、展开箭头、标签、可选数量 | 左右键收展，上下键移动；懒加载状态在对应节点；错误重试不重置整树 |
| Empty State | R | 简短标题、原因、单个主要行动 | 首次空、无结果、权限限制分开；无权限不可建议创建；不使用大插画 |
| Skeleton | T | 对应真实布局，统一浅灰 | 本身不接焦点；容器 aria-busy；Error 后必须换成错误提示，不能无限闪动 |
| Progress | R | 百分比 / 进度文字 + 轨道 | 确定值用 aria-valuenow；未知进度不伪造百分比；Error/取消保留最后可信状态 |
| Result | R | 结果图标、标题、摘要、下一步 | 成功、失败、中性各自文案；危险结果不能自动消失 |

分页信息和可复制标识不能使用装饰性弱灰。刷新旧数据期间明确标记“更新中”，失败后标记“当前显示上次成功获取的数据”，不得把陈旧数据显示成刚刚成功更新。

## 6. Feedback

按影响范围选择组件：字段问题用 Inline Error，区域失败用 Alert，短暂完成用 Toast，需要决定用 Dialog。不要用一种 Toast 承担所有错误。

| 组件 | 状态族 | 规范 | 特殊状态与行为 |
| --- | --- | --- | --- |
| Alert | R | 区域内消息，图标、标题、说明、可选行动 | 中性 / 信息 / 成功 / 警告 / 错误；关键错误不自动隐藏 |
| Toast | R | 浮层短反馈，默认约 4 秒 | Focus/Hover 暂停关闭；重要错误与待操作通知保持至处理；aria-live polite |
| Message | R | 与触发操作就近的轻量反馈 | 使用同一消息语义与 Sonner/Alert，不再造第二套全局消息系统 |
| Modal | O | 宽 480–640px 常规对话框，16px 圆角 | 焦点陷阱；Escape/关闭遵循未保存规则；内部 Loading/Error 不关闭对话框 |
| Drawer | O | 400–560px 辅助编辑，最多占视口合理比例 | 窄屏可全屏；固定标题与操作区；模态 Drawer 管理焦点并提供关闭入口 |
| Confirmation Dialog | O | 明确对象、后果、取消与具体动作 | 默认聚焦取消等安全项；确认后 Loading 防重复；失败保留弹层；不使用泛化“是/否” |
| Error Page | R | 可理解的原因、返回 / 重试 / 联系方式 | 403/404/500/503 分开；不暴露堆栈与敏感信息；权限不足不提供无效重试 |
| Loading State | R | 局部优先；与内容大小匹配 | 初次 Skeleton，局部刷新保留内容；超过预期说明仍在加载，并可取消时提供入口 |

Modal 和 Drawer 不嵌套多层编辑弹窗；确需二次确认时保留原表单和焦点返回位置。关闭按钮始终可达。保存成功才关闭；取消是否丢弃取决于 dirty 状态，不能一律弹确认。

提示优先级：必须采取行动的错误 → 当前操作反馈 → 一般信息。避免高频成功 Toast；连续同类提示合并数量，不能刷屏。通知中心中的历史消息与即时 Toast 共享来源，但不是 Toast 文本的随意缓存。

## 7. Chart 组件

以下均继承 G 状态族，颜色、坐标和口径遵守[图表规范](design-language.md#9-图表规范)。

| 组件 | 结构 | 特殊状态 |
| --- | --- | --- |
| Line Chart 折线 | 标题、单位、时段、坐标、图例、数据表入口 | 缺失时段断线；选中使用点标记与线型，Error 不保留误导曲线 |
| Bar Chart 柱状 | 从零起的数量轴、固定顺序、可读分类 | Hover/Focus 可读精确值；零值可显示标签而非“无数据” |
| Stacked Bar 堆叠柱 | 固定系列顺序，计数或百分比明确 | 关闭系列后说明分母是否变化；数据无效时不画 100% |
| Donut 环形 | 总数 / 核心指标、分布图例、数量与比例 | 无样本改空态；单一类可完整成环并显示标签；极小值保留图例 |
| Sparkline 迷你趋势 | 相邻数字、变化量、时段 | 无独立选中行为时 Selected —；加载不使统计卡跳高 |
| Result Distribution 结果分布 | 状态图例 + 分布 + 计数 | 状态色固定；Selected 筛选有清除入口，不能静默改变其他图口径 |
| Success Trend 成功率 | 百分比、样本数、时段、分母说明 | 无分母用“—”；局部放大轴明确标注；波动提示不自动推断根因 |

图形详情可以用 Tooltip，但完整信息必须有键盘与文本等价入口。图表本身不需要额外独立 Loading 框架。

## 8. 跨组件异常状态

下列状态是全局交互约定，不代表已经存在对应业务功能。

| 状态 | 展示位置与文案原则 | 操作 / 数据保留 |
| --- | --- | --- |
| 首次进入空状态 | 主内容区：“还没有内容” + 具体对象名 | 有权限时提供唯一主要创建入口；不要显示全零统计 |
| 无搜索结果 | 保留搜索框与已选条件 | 提供“清空筛选”；不跳到首次空态 |
| 初次加载 | 内容位置等尺寸 Skeleton | 导航与取消保持可用，不全屏白屏 |
| 加载失败 | 失败区域内原因摘要 | 保留上下文和查询条件，提供重试 |
| 权限不足 | 必要时整页；局部权限用局部说明 | 提供返回或联系管理员；不暴露无权限数据 |
| 数据量很大 | 总数、当前范围、分页 / 按需加载 | 不渲染全部数据；筛选不丢选中范围语义 |
| 长任务进行中 | 持续状态 + 已知进度 + 最近更新时间 | 允许查看已有内容；支持取消时说明取消请求与已取消的差别 |
| 部分失败 | 容器总览 + 失败项标记 | 成功项仍可查看；解释部分范围，不能整页涂红 |
| 网络断开 | 页面级细提示，显示最后更新时间 | 保留已加载数据与未保存输入；重连后恢复查询，不伪造成功 |
| 依赖节点不可用 | 相关动作旁提示原因与范围 | 暂停依赖动作，其他区域仍可读；重试前不清空配置 |
| AI 服务不可用 | AI 区域局部错误 | 保留输入；人工编辑可用；不升级为整个平台不可用 |
| AI 正在生成 | AI 区域进度文字、取消入口 | 不将半成品悄悄应用；生成结束进入待审阅状态 |
| 用户取消 | 中性完成反馈 | 已停止和正在请求停止分开；不把取消显示为红色系统错误 |
| 表单未保存 | 标题附近标记未保存 | 离开 / 关闭触发明确丢弃确认；保留本地输入 |
| 多人编辑冲突 | 编辑区域中断提交并说明新版本 | 保留自己的草稿，提供比较 / 重新载入；不静默覆盖远端 |

实时到达的数据不应不断改变用户当前阅读位置。大列表的新增记录可提示“有 N 条更新”，由用户刷新；具体必须实时跟随的场景另定交互规则。

## 9. 危险操作与反馈文案

确认对话框使用完整动作，例如“删除此配置”，标题明确对象；正文说明影响范围、是否可恢复以及依赖关系。取消为默认安全焦点。只有不可逆且影响范围大的动作才要求额外输入对象名，不给普通操作增加负担。

操作完成：明确说“已保存”或“已提交请求”，不能在异步任务尚未完成时说“已完成”。失败说明“哪一步没有完成、输入是否保留、可以做什么”。敏感值不出现在 Toast、错误信息和示例日志中。

AI 建议必须可审阅，接受与拒绝是显式动作；提出建议与应用建议分离。组件只提供此通用交互，不定义具体 AI 业务模块。

## 10. 组合边界

- 使用单一 Page Header 组织标题和操作，同页不反复放置多个同等强调的“主按钮”。
- 使用 Table Toolbar 组合 Search、筛选、排序和批量操作，不为每个列表复制一套视觉实现。
- 表单项组合 Label、Control、Description、Error，校验和可访问关联由现有 Form 体系处理。
- 特定领域组件未来可组合 Card、Badge、Timeline、Tabs 等基础组件；本轮不定义步骤编辑器、证据面板或完整业务页面。
- 不预先增加循环、分支、恢复执行等能力的可点击占位。业务范围由领域与功能方案决定，不由组件清单扩张。
