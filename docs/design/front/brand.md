# 识途品牌与 Logo

版本：v1.0 · 更新：2026-09-10 · 状态：已选择 B · 观测证据

三个方案共用识途主蓝、圆角方形容器和白色符号。B 已确认为正式方向，并接入登录页与浏览器图标；A、C 仅保留为方案记录。

## A · 路径标

![路径标](../../../packages/web/src/assets/brand/logo-path.svg)

连续路径连接起点和终点，同时形成隐约的 S，表达 Scenario 的顺序执行与“识途”的路线语义。轮廓最简洁，小尺寸识别度最好，适合作为默认产品图标。

## B · 观测证据（已选）

![观测证据](../../../packages/web/src/assets/brand/logo-observe.svg)

圆形观测窗口承载四个连续执行节点，表达 Run 的过程、Evidence 与可复盘性。外轮廓保持稳定，内部轨迹在小尺寸下仍能识别。

## C · 叠石路标

![叠石路标](../../../packages/web/src/assets/brand/logo-cairn.svg)

叠石对应 Cairn 的原始含义，也表达路标与可靠引导。故事性最强，适合强调产品名称来源；在极小尺寸下更接近通用的层级或数据符号。

## 使用约束

- 图标与“识途”字标并列时，图标高度等于两行字标总高度。
- 24px 以下只使用图标，不放副标题。
- 图标四周至少保留图标宽度四分之一的净空。
- 产品界面只使用 B，不改变内部比例、不加渐变。
