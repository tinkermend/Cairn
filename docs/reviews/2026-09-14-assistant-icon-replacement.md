# 助手头像替换、自由拖动与素材清理

日期：2026-09-14。范围：[平台助手一期交互](../spec/2026-09-14-platform-assistant-phase-one.md#7-交互与组件复用)的头像与悬浮入口。按前端验收 skill 进行局部验收，因为本次新增了拖动、位置记忆和键盘操作。

用户确认采用亲和观测员，随后要求去掉头像外围的白色圆底，并允许自由移动。正式素材为 [assistant-observer-v1.png](../../packages/web/src/assets/brand/assistant-observer-v1.png)。入口现在只显示 56px 头像，无外层底色、边框或阴影；图像按原比例收紧透明边距，面板头像按当前浮窗标题栏使用 36px 容器。

[入口组件](../../packages/web/src/features/assistant/launcher.tsx)复用现有 Button 和 Popover；鼠标与触控拖动超过 6px 才视为移动，松手不会打开弹窗，取消恢复原位。相对位置保存在本浏览器，刷新恢复，窗口缩小时保持可见；存储异常不阻塞使用。方向键可微调，右键／键盘菜单提供方向控件与重置，Home 恢复默认位置。已有助手权限与业务能力保持原契约。

## 2026-09-14 图标加载体积修正

用户从浏览器审计发现 56px 入口下载了 784.8 KiB PNG。核查发现入口与面板都直接引用原图，使用样本的 32 / 40 / 48 / 56 / 80px 只是 CSS 展示尺寸，仓库没有对应的小尺寸文件。

- 从同一原图导出 70 × 56、140 × 112、210 × 168 透明 WebP，分别为 1900、4272、7190 字节。入口和面板通过 `icon.ts` 共用 `srcSet`，按 `sizes` 与设备像素比选择；原 PNG 保留为素材源。具体尺寸和再生成方式见[素材说明](../design/front/assistant-friendly-observer-v1.md)。
- 在已登录的 [运行列表](http://localhost:5173/runs) 刷新，Chrome Network 按 `assistant-observer resource-type:image` 筛选仅出现 `assistant-observer-v1-140.webp?no-inline`，资源为 4272 字节（4.17 KiB），没有原 PNG 请求；该次为 304 缓存验证，网络传输为 127 字节，不能把缓存响应大小当作图片体积。打开助手面板复用同一图片，没有额外图像请求；入口和面板头像显示正常。未重新跑完整 Lighthouse 评分。
- 轻量验收：现有入口与宿主 14 项浏览器组件用例、三个修改源码文件的 ESLint、`pnpm check:design` 通过。`pnpm --filter @cairn/web exec vite build` 通过，产物只包含三档 WebP，原图不进入产物，小图保持独立 URL。
- 完整 `pnpm --filter @cairn/web build` 的类型检查被本任务范围外的 4 处错误阻塞：`studio.test.tsx` 两处 StepRun 样本缺 `name/type`，`targets/detail.test.tsx` 使用当前 lib 不支持的 `.at()`，`workers-api.ts` 默认参数缺必填 `limit`。本任务未修改这些文件；不将独立资源打包通过写成完整构建通过。
