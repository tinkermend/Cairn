# 目标知识 · 知识资产全景（群岛视图）原型

直接打开 [index.html](index.html) 即可运行。目录仅包含独立 HTML、CSS、JavaScript 与静态海水底图；不依赖现有 Web 代码、不调用 API、不修改知识资产。全部名称、时间、计数与场景引用都是固定演示数据。默认展示 16 个菜单入口的综合业务系统；另有两个 3 页小系统用于对比。

原型定位为某个目标系统下的“目标知识 → 知识资产全景”群岛视图，不是目标系统首页，也不增加“知识”一级菜单。现有前端路径是“目标系统 → 系统详情的「知识」按钮 → 目标知识页”，该页默认展示“知识资产全景”标签；正式接入时，群岛应成为该标签内与列表并列的呈现方式。目标系统详情仍承载该系统的状态和操作入口；群岛聚焦平台已认识的页面、对象、验证状态及引用。外层模拟识途现有的浅色工作台：固定 208px 侧栏、64px 顶栏、冷灰内容画布，侧栏高亮“目标系统”。深海色仅留在知识海图视窗内；标题、图例、筛选与对象详情由浅色工作台承载。这个外壳是视觉融合示意，侧栏和顶栏不承载平台导航、全局搜索或登录功能；可操作区域从目标系统选择器开始。

## 如何操作

- 已加载页面多时，知识全景直接呈现页面岛屿；桌面海域首屏约见八座，纵向滚动看其余岛屿。轻量海域航标保留演示分区，不用矩形分区卡挡住岛屿。进入页面后选对象地标；详情展示生命周期、验证维度、变化、证据可用性与场景引用。
- 可以切换目标系统、按状态筛选、搜索页面/路径/对象，或转到完整页面列表。总览时海图占满内容宽度；进入页面后浅色详情区展开。`/` 聚焦搜索，`Esc` 逐层返回。
- 窄屏岛屿自动减列并继续纵向滚动，不依赖拖拽、悬停或三维相机。对象与场景关系保留在浅色详情区，不在深色海面放说明卡或虚构导航航线。

## 群岛排布与海水底图

桌面总览不使用整齐的四列格子。每个演示海域用页面 ID 生成稳定的候选位置，给完整岛屿按钮（岛面、文字和下方状态）预留点击盒与间距，再从无碰撞的候选中选择纵向错落、横向间距不等的一组。进入页面再返回、切换对象状态时位置保持不变；按已加载对象量只做小幅岛屿尺寸调整，不表达菜单优先级或页面之间的真实距离。窄屏改为双列或单列流式布局，避免随机坐标造成遮挡。海岸线有多种稳定轮廓，减少复制感。

[海水底图](assets/ocean-surface.webp)由内置 imagegen 生成，并压缩为 WebP；[生成提示词](assets/ocean-prompt.txt)保留在目录内。它只包含低对比度深蓝绿海水，没有预先画岛、浅滩、航线或文字，避免和运行时岛屿坐标冲突。页面同时保留 CSS 深海渐变，图片加载失败仍可阅读；地图上的名称、状态和点击区继续由代码绘制。

## 一个页面有十几个按钮时

页面海岛不逐个放按钮：它只展示页面名称、对象总数与待复核提示。进入页面后，岛面显示少量功能分区的概览；完整按钮目录放在浅色详情区，支持按名称查找并逐项进入对象详情。视窗变窄时，详情区移到海图下方。原型用“订单中心”演示高密度页面，分区名称仅是 fixture 配置；现有 Map 对象数据并不天然提供可靠的业务功能分组。正式接入需由目标系统导航／区域元数据或用户确认来决定分组，缺少时按已加载对象给出中性列表。按钮入口在这里是被识别的知识对象，不代表原型或平台能直接代替用户执行业务操作；大于一屏的目录应继续分页或按需加载。

## 落地边界

页面岛屿只代表页面分组，地标位置是稳定的阅读布局，不代表真实网页坐标；岛屿之间没有导航或执行顺序。对象变化表示需要复核，不等于关联场景执行失败。场景关系若在正式版重新画线，只给 `confirmed_reference` 且 `resolution=resolved` 的场景画实线；`potential_match` 用虚线。`unknown_coverage` 是目标级扫描覆盖信息，不能计入单个对象的关系数量，只显示范围说明。演示维度在界面规范化为“确认 / 否定 / 未知 / 未观察”；正式接入应直接读取 `MapDimensionStat.verdict`，变化待复核仍保持独立状态。

当前 Map 接口支持目标系统→页面→对象、生命周期、验证维度、最近验证、证据可用性、变化与引用。它尚无可靠的业务菜单树、父级、顺序或页面友好名称，16 页示例里的业务分区和名称由演示 fixture 提供。正式接入需要目标系统导航元数据或用户确认的配置；缺少时应按已加载页面做中性的顺序分区，并用路由模板或“待命名页面”作标签，不能把 URL 路径推断成真实菜单层级。页面和对象列表按游标分页；本原型所有汇总均标注“已加载”，正式数据聚合还需锁定同一地图投影或发布版本，避免混合不同修订的事实。
