# 识途前端浅色视觉方向提案

日期：2026-09-10。状态：视觉评审草案，尚未选择最终品牌色。

## 已确认的用户偏好

**识途所有主题以浅色为核心。** 用户在本轮明确强调：“我们那个主题都以浅色为核心”。

本轮三套提案均采用浅色工作区、浅色导航、白色内容面板和少量强调色；后续视觉设计以此为默认。这里记录设计偏好，不将颜色或像素值写成架构宪法。

用户提供的财务后台截图用于参考色彩层次、明亮度和留白；不复制品牌、业务内容、布局或图表。

## 现有界面与设计判断

当前 `packages/web/src/styles/theme.css` 以白底、深色主按钮、灰色交互面为主，品牌强调较弱；`features/dashboard/index.tsx` 仍保留营收、订阅、销售等管理模板示例。当前导航主要包含 Dashboard、Tasks、Users、Roles、Audit、Settings。

识途的核心工作是绑定真实目标系统、编排可检查的步骤、执行并复盘。视觉应帮助用户识别当前目标、步骤顺序、运行状态和证据，首页内容需要跟随这些工作变化。

本提案基于现有代码、项目宪法、MVP 路线图及 Scenario Authoring 的 Studio UI 设计。三套颜色属于本轮原创设计判断，不代表已实现的业务能力。

## 三套浅色方向

| 角色 | A 雾紫（推荐） | B 青瓷绿 | C 冰川蓝 |
| --- | --- | --- | --- |
| 气质 | 柔和、轻盈、有辨识度 | 温润、沉静、低刺激 | 清爽、理性、控制台感 |
| 工作区 | `#F5F5FA` | `#F4F5F0` | `#F3F7FB` |
| 面板 | `#FFFFFF` | `#FEFFFC` | `#FFFFFF` |
| 浅色导航 | `#F0F0F7` | `#E8F0E9` | `#EAF1F8` |
| 主色 | `#6258C9` | `#16766C` | `#3D70BC` |
| 选中浅底 | `#ECEAFB` | `#E4F0EA` | `#E6EEFB` |
| 正文 | `#252638` | `#233D39` | `#23344B` |
| 边框 | `#E4E5EF` | `#DDE5DC` | `#DCE6F0` |

推荐 A：以柔紫标记主操作、选中步骤和导航，适合用户给出的审美方向。紫色只占少量面积，让文字、业务截图与状态信息仍是视觉中心。B 更温润；C 更接近传统专业控制台。

品牌色与状态色分开使用。三套方案固定使用蓝色表示运行中、绿色表示成功、琥珀色表示待处理、红色表示失败，同时配合文字和图标。AI Action、AI Extract、AI Assert 通过类型标签区分，不按三套独立执行模式设计。

## 布局与领域模块

### 工作台

左侧固定导航，顶部显示空间和当前位置。主体上方展示今日运行、成功率、正在执行、需要关注；中间展示健康趋势和最近运行；右侧放待处理事项、目标系统与会话概况。最近运行可进入统一的运行详情。

第一版不用财务营收图、装饰性环图或大量无关统计占用主要空间。目标账号归属目标系统；控制台成员与权限单独管理。

### 场景编排

遵循已有 Studio 设计：左侧步骤库，中间有序步骤链，右侧当前步骤配置，下方试运行与证据入口。确定性与 AI 步骤在同一序列中混排。

页面顶部始终展示目标系统、目标账号和草稿/版本状态。AI 配置保存业务意图和输出契约。截图中自由组合的是顺序步骤，不提供自由分支、并行或任意跳转。

### 运行与证据

左侧按原顺序展示步骤与结果，右侧查看选中步骤的截图、AI 判断、输入/输出、尝试记录及事件。失败用局部提示和标记表达，保持页面浅色。

历史运行明确使用自己的冻结版本；原型中的历史运行是 v1.7，编辑页草稿基于 v1.8。Attempt 失败与 StepRun 最终失败分别表达。截图关联 Run / StepRun / Attempt，并用脱敏示意业务页面帮助理解。

### 其他模块的布局方向

- 目标系统：以系统列表进入详情，目标账号、入口与策略归属各自系统。
- 巡检调度：计划表为主，突出所用场景、周期、下一次执行和最近结果。
- 浏览器会话：表格展示目标与账号、健康/认证状态、使用情况和有效期，区分可复用会话与单次独占使用权。
- 模型路由、成员权限、审计日志：采用列表与详情面板，延用同一浅色体系。

## 本轮产物与边界

[打开原型](prototypes/ui-directions-2026-09-10/index.html)。可切换三种浅色主题和工作台、场景编排、运行详情；可选择步骤、编辑并应用示例配置，以及切换证据内容。

原型使用虚构示例数据。目标系统详情等未展开入口显示说明；新建、录制、试运行、保存、导出不调用正式服务。本轮没有修改应用源代码、安装新依赖或实现业务功能。

三套主题采用相同核心信息架构，方便直接比较颜色；工作台、编排页和运行详情各自采用符合任务的布局。桌面宽度为主要评审对象，窄屏用于阅读与基本操作验证。
