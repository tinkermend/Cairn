# 识途录制器：工作台收敛与设计语言对齐

日期：2026-09-13。状态：**已落地**。  
范围：把现有 Side Panel 从「Playwright 代码生成器 + 登录条」收成识途 Authoring 工作台：登录门禁、平台视觉、核心采集操作、步骤列表。采集引擎与上传契约沿用已落地的[登录与录制上传](2026-09-13-extension-login-and-recording-upload.md)。

视觉样本：[侧栏工作台原型](../front_design/2026-09-13-extension-workbench/index.html)（约 380px，模拟数据）。

## 1. 对当前说法的判断

**方向对，MVP 可行，但原文还少几条必须写死的边界。** 不补这些，要么继续露出 Playwright 代码窗，要么就会去改采集内核、或把 Midscene / page-agent 揉进同一个扩展。

已经说清楚、应当照做：

1. 插件视觉跟控制台同一套设计语言（浅色、冷蓝白、语义色）。
2. 没登录不能用；登录就是控制台账号密码，和平台绑定。
3. 平台地址不让用户手填。环境名单写在代码里；登录页只用下拉选名称，不写标题、不展示地址。本期名单只有「本地开发环境」。
4. 不要 Python / Java / C#，也不要「代码语言」下拉。
5. 产品主界面不要主题深浅切换。
6. 工具条只留核心：录制、点选元素。
7. Midscene / page-agent 的「第 1 步、第 2 步」是正确的产品形态，但本期只学交互，不换引擎、不拷它们的扩展。

原文里还含糊、方案里拍板的：

| 含糊点 | 决定 |
| --- | --- |
| 「只要 JS library」和「连选项都去掉」 | 用户看不见任何语言。引擎内部锁 `javascript`（对应 Playwright 的 Library）。上传仍读 JSONL `actions`，不是生成脚本。 |
| 平台 API 给用户填还是选 | 地址只在代码里定义。登录页只显示环境下拉（选项是 `label`），不写「环境」标题，也不展示 URL。本期只有本地开发环境。以后加测试 / 生产，只在同一份名单里加行。 |
| 登录门禁只藏 UI 够不够 | 不够。未登录时 **不得** `attach` / 开 `chrome.debugger`。工具栏点击只打开登录页。 |
| 断言、回放、复制、日志、Aria | 本期全部从产品 UI 拿掉。断言以后单独加；Player 永远不是正式 Run。 |
| 代码窗还要不要 | 拿掉。主界面是编号步骤列表，和平台「录制草稿」同一套 IR 文案。 |
| 要不要现在做 AI 讲步骤 | 不做。现有 IR 名称（打开 / 填写 / 点击）够用。AI 润色是下一步，紫色入口，不得改采集事实。 |
| 设计对齐是不是把 Tailwind / shadcn 搬进插件 | 不是。插件导入同一份 `tokens.css`，用原生 CSS。不引入第二套 UI 框架。 |

**不可行 / 不要做的理解：**

- 不要为了「好看」重写 `playwright-crx` 采集，也不要新开第二个扩展。
- 不要把 Midscene、page-agent 的包编进本扩展。
- 不要把 Playwright codegen、storage state 当 Scenario 事实源（已有硬约束，本期不改）。
- 不要在插件里做完整编排或正式执行。

## 2. 目标与非目标

### 目标

1. 未登录：侧栏只有登录。账号 + 密码。主按钮一个：「登录」。
2. 已登录：才能挂 tab、录制、点选、选 Target、上传草稿。
3. 主界面是步骤轨迹，不是代码编辑器。
4. 视觉消费平台 Token：表面分层、主蓝操作、成功绿 / 警告橙 / 失败红；默认浅色。
5. 采集、归一化、幂等上传、控制台草稿页沿用现网，不另造协议。

### 非目标

- 不换采集引擎，不 fork `vendor/` 去改 Recorder 内核。
- 不把 Midscene / page-agent 扩展或 Antd 时间线拷进来。
- 不在本期接模型、不生成「第一步讲的话」。
- 不恢复断言模式、Player、多语言、主题切换、手填 API 地址、实验「保存代码 / 下载 storage state」。
- 本期不往环境名单里加测试 / 生产；名单结构先写好。
- 不把草稿编译成 `ScenarioVersion`。
- 不在插件里做配对码 / 刷新令牌。

## 3. 决策

### D1. 产品壳替换 Playwright 录制器窗口，采集进程不动

今天 Side Panel 实际是上游 `Recorder`：工具条 + CodeMirror + 定位 / 日志 / Aria。登录条只是叠在上面。这就是截图里「像 Playwright 不像识途」的原因。

本期 **不再把 `<Recorder>` 当作产品主界面**。`src/cairn/` 自己画：

```text
未登录：登录页
已登录：顶栏（账号 / Target / 上传）
        工具条（录制 / 选取 / 清空）
        步骤列表（IR）
        选取时：当前元素读数
```

`crxRecorder.tsx` 继续收 `sources` / `mode`，向引擎 `dispatch` `setMode` / `clear`。JSONL 提取与 `normalizeRecording` 不变。

`vendor/playwright-recorder/recorder.tsx` 不作为用户界面维护。升级上游时不必再为「代码语言」四个字重打汉化；产品文案都在 `src/cairn/`。

内部仍调用：

```ts
recorder.show({ language: 'javascript', ... })
```

只为让引擎产出稳定的 Library 语义。面板不展示这段代码。上传继续 `sources.find(id === 'jsonl')`。

### D2. 登录是门禁，不是工具条上的一行

| 动作 | 未登录 | 已登录 |
| --- | --- | --- |
| 点扩展图标 / 快捷键 / 右键「挂到识途录制器」 | 只开 Side Panel 登录页，**不 attach** | 开工作台；用户再点「录制」才挂 tab |
| 侧栏里点「录制」「选取」 | 控件不存在 | 才 `attach` + `setMode` |
| `GET /api/me` 401 / 过期 | 清 token，回到登录；已挂上的会话 detach | — |

Token 仍在 `chrome.storage.local`。打开工作台先 `GET /api/me`。没有 refresh。viewer 能登录、能看自己的步骤预览；无 `workflow:write` 时「上传到平台」禁用并说明原因。选 Target 仍要 `target:read`。

不要：读控制台 cookie、登 TargetAccount、插件自己的用户表。

### D3. 平台环境写在代码里，用户不填地址

```ts
// packages/extension/playwright-crx/src/cairn/config.ts
export const CAIRN_API_ENVIRONMENTS = [
  {
    id: 'local',
    label: '本地开发环境',
    origin: 'http://localhost:3030',
  },
] as const
```

登录、`/me`、Target、上传都打当前环境的 `origin`。`host_permissions` 按名单里的 origin 声明。用户界面删除自由输入的「平台 API 地址」。

登录页只放环境下拉，不写「环境」标题，也不展示 URL。下拉只列出代码里的 `label`，用户不能键入地址。本期名单只有「本地开发环境」。以后加测试 / 生产，只在这份名单里加行。

切换环境会清掉当前 token（另一套 API 不能沿用同一登录态）。本期只有一项，不会走到切换。

扩展 fetch 继续走 host permission，不把 `chrome-extension://` 塞进 `CAIRN_CORS_ORIGINS`。

### D4. 步骤列表是产品表面，代码不是

列表数据 = 现有 `normalizeRecording` 的 `items`，与控制台草稿详情同一套名称 / 状态：

| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| 已映射 | 中性 + 成功点 | 能变成平台 Step |
| 待补参数 | 警告橙 | 敏感填写已剥明文 |
| 待处理 | 警告橙 | 能录到、本期不能变成 Step（如 select） |

文案用 IR 已有中文名（「打开 lab.example/orders」「填写」「点击」），编号从 1。空态：「开始录制后，操作会按顺序列在这里。」

只有中文名不够：连续点几个按钮会出现一串一模一样的「点击」，用户无法判断录到了哪个元素、录错没有。每步再给两层：

1. 标题下一行是定位摘要，优先语义定位（`button「查询」`、`标签「订单号」`），没有语义定位才退回 CSS；
2. 「展开」显示该步的原始字段（`sourceAction`、`candidateStepType`、`framePath`、平台 `input`），与控制台草稿详情同一套字段，只读。

展开是渐进式展示，不是代码编辑器：这里给的是采集事实，不是可编辑脚本。

这已经是 Midscene 时间线要的信息结构。差别只在：我们用平台 IR，不用它们的 event / Antd Timeline。

**第二步（本期不做）**：紫色「用 AI 写步骤说明」。只改展示文案，不改 `events`、不改上传包、不静默替换 Step 意图。等平台有 Authoring 用的模型路由再单独立项。

### D5. 工具条只留采集必要项

| 保留 | 去掉 |
| --- | --- |
| 录制（主操作，录制中为选中态） | 代码语言、主题切换 |
| 选取（点选元素，看定位） | 断言可见 / 文本 / 值 / 快照 |
| 清空（次操作，清本段轨迹） | 复制代码、继续 / 暂停 / 单步 |
| 上传到平台（已登录且有步骤时的主业务动作） | 日志页、Aria 页、CodeMirror |
| 退出 | 偏好：语言、手填 API、实验功能、无痕回放 |
| | 实验条「保存代码 / 下载 storage state」 |

选取仍有用：用户要确认「点到的是哪个元素」。结果用一小条只读说明（角色 / 文本 / 选择器摘要），不用代码编辑器。

「清空」不是核心卖点，但没有它无法重录。做成 Ghost / 文字按钮，点后确认「清空本段未上传步骤」。

### D6. 侧栏归属：录制器每次接管都要换一次路径

产品壳自己打开侧栏之后，vendor 的接管时序会失效，表现就是面板里的「录制」「选取」点了没反应，只有点浏览器工具栏图标才动。原因是两条约束叠在一起：

1. `playwright-crx` 的 `SidepanelRecorderWindow` 先注册一次性 `chrome.runtime.onConnect`，再 `sidePanel.setOptions({ path })`，然后一直等这个新连接，`recorder.show()` 才返回；
2. Chrome 的 `setOptions` 路径没变时不重新加载侧栏页面。

侧栏已经开在同一路径时，页面不会重连，`show()` 永远挂着，`attach` 也就不返回。点工具栏图标碰巧让侧栏重载、补上这个连接，才是「只有顶部按钮有反应」的真相。

边界写死：

- 每次 `recorder.show()` 用一个新的侧栏路径（`index.html?panel=N`），保证页面重载并重连；
- `sidePanel.open()` 只在挂接路径上做兜底：面板发起挂接时侧栏已经开着，而这个调用隔了几个 `await` 已经没有用户手势，Chrome 会直接拒绝，不能让它决定挂不挂得上；
- 挂哪个标签页按用户视角定：侧栏不抢标签页焦点，所以优先当前活动标签页，活动页是扩展页或 `chrome://` 时才退回上次记住的那个，最后才挑一个真实页面而不是 `about:blank`；
- 录制器已经接管侧栏时，产品侧不得再改侧栏路径——重载会断端口，vendor 会把断开当成关闭录制器，正在录的这一段会被停掉；
- 接管等待必须有上限，超时给出可执行原因，不允许按钮静默卡住；
- 接管会重载面板，因此选中的 Target 存进 `chrome.storage.local`，重载后接回来；未上传的步骤本来就在引擎侧，重连后由 `setSources` 重新推给面板。

### D7. 视觉对齐：同一 Token，不同运行时

| 必须统一 | 不要做 |
| --- | --- |
| `docs/design/front/tokens.css` 的语义色、字号刻度、圆角、输入边界 | 在插件里另选蓝 / 另做暗色 |
| 登录：白卡片、主蓝按钮、标签在上、账号 / 密码 | 把 Web 的 Tailwind、Radix、整页 AuthLayout 打进 MV3 |
| 工作台：`surface-page` 画布 + `surface-card` 步骤卡 | 绿色当登录主色（绿只表示成功） |
| 一张面板同一时刻一个主操作：未登录是「登录」，已登录未录是「录制」，有步骤是「上传到平台」 | 登录按钮做成成功绿；多个实心主按钮并列 |

插件是 Side Panel（约 360–400px），不是控制台工作区。布局按窄栏重排：登录单列；顶栏可折行；步骤卡全宽。控件高度用 36px（侧栏）而不是登录页 48px，避免一屏只放下两个输入。

默认 `color-scheme: light`。不提供切换。vendor 主题模块可以留着，只要产品 UI 不再调用 `toggleTheme`。

## 4. 界面结构

### 4.1 登录

```text
[观测标] 识途
        录制器

登录识途
用控制台账号进入。没有登录不能录制。

[ 本地开发环境 ▾ ]

账号
[                    ]
密码
[                    ]
[        登录        ]

错误时：红字 + 原因，保留已填账号。
```

对齐控制台登录文案（「登录识途」「请输入账号」「请输入密码」）。环境只留下拉选名称，不能手填地址。输入框必须落在登录卡片内，不能横向溢出。

### 4.2 工作台

```text
识途录制器                    Administrator  退出
目标系统  [ Browser Surface ▾ ]
[ 上传到平台 ]

[ 停止录制 ]  [ 选取 ]          清空

● 正在录制当前标签页，已记录 4 步

1  打开 lab.example/orders            展开
   已映射 · navigate
2  填写                               展开
   #orderNo
   已映射 · fill
3  点击                               收起
   button「查询」
   已映射 · click
   { "sourceAction": "click", ... }
4  选择                               展开
   #status
   待处理 · 下拉选择尚无对应 Step Type
```

主操作跟状态走，一屏只留一个实心蓝：没录到步骤时是「开始录制」，录到了才轮到「上传到平台」，录制中录制键变「停止录制」并保持选中态。  
录制中：状态行是蓝点 + 「正在录制当前标签页，已记录 N 步」，不用红色（红色只留给失败）。  
选取中：按钮变「停止选取」，状态行给出当前元素读数。  
无 Target / 无步骤 / 无写权限：上传禁用，旁边一句原因。

## 5. 落地边界

只动壳与样式，不动引擎：

| 改 | 不改 |
| --- | --- |
| `src/cairn/` 登录页、工作台、步骤列表、Token 样式 | `playwright-crx` 引擎、`getActions()`、vendor 采集 |
| `background.ts`：未登录不 attach | 上传契约、`normalizeRecording`、草稿表 |
| `settings`：内部语言锁 `javascript`；删掉用户可改的语言 / 手填 API / 实验项 | 控制台草稿页的信息架构（可随后把插件步骤卡做得更像它，不要求本期改 Web） |
| `crxRecorder.tsx`：按登录态渲染 cairn，不再挂 `<Recorder>` | 把登录按钮打进 `vendor/playwright-recorder/recorder.tsx` |

偏好页若不再有任何用户设置，整页隐藏。`testIdAttributeName` 维持默认 `data-testid`，不暴露。

## 6. 验收

1. 未登录：点图标只看到登录；页面上没有 debugger 黄条（未 attach）。
2. 错误密码：红字原因，不进入工作台。
3. 登录页环境是下拉，当前只有「本地开发环境」；没有「环境」标题，没有地址文字或地址输入框。输入落在卡片内。登录后：无语言下拉、无主题钮、无代码窗、无 Python。
4. 登录后才能录制；步骤按 1、2、3 出现，文案与上传后的控制台草稿一致。
5. 选取能指出当前元素，不打开代码编辑器。
6. 上传仍走 `POST /api/recordings`，幂等与敏感规则不变。
7. 退出后回到登录；再次点图标不能在未登录时挂 tab。
8. 窄栏（约 360px）登录与工作台都不横向溢出；主按钮仍是蓝 600，不是绿。
9. 浏览器里打开[原型](../front_design/2026-09-13-extension-workbench/index.html)对照：登录页和工作台的层次、主操作、步骤状态色。
10. 面板里点「录制」「选取」就能挂上当前标签页，不需要先点浏览器工具栏图标；停掉再录第二段同样能挂上；接管失败有超时原因，不静默卡住。
11. 连续点多个按钮时，每步能靠定位摘要区分；展开能看到该步原始字段，字段与控制台草稿详情一致。
12. 接管导致侧栏重载后，已选 Target 和已录步骤都还在。

## 7. 现在不做

AI 步骤说明、断言录制、草稿编译、配对码、往环境名单加测试 / 生产、暗色主题、把插件步骤同步编辑进 Scenario Studio。
